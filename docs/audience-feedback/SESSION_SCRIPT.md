# Audience session script (issue #8)

**Status: script only; no session has been run.** About 15 minutes per viewer. Record in a copy of [SESSION_TEMPLATE.md](SESSION_TEMPLATE.md), using the viewer's own words. No names or student IDs.

## Before

- Start the app (`streamlit run app\story.py`) on a laptop or projector; note the commit (`git rev-parse --short HEAD`).
- Pick viewers who do not follow F1 closely, plus one or two fans.
- Say: "This is a test of the chart, not of you. I can't explain it until you've answered."

## Ask first (30 seconds)

- Teammate or F1 fan? How often do you watch F1? Have you looked at lap-timing data before?

## For each view (charts 1 to 5, then Extra if time allows)

1. Show it with no explanation. "What do you think this shows?"
2. "What is the main point, in one sentence?" Note the seconds taken (target about 60).
3. "Is any word, colour or label confusing?"
4. Only after they answer: "Did the box above the chart help?"

## Interpretation checks (after chart 5)

- "What does a gap between two drivers mean here?"
- "Is pit-lane time the same as the time the car is stopped?"
- "Does tyre age tell you how worn the tyres are?"
- "What would you conclude about this race?" Write down any conclusion the data cannot support.

## Also note

- Did they find the arrows without help? Did they open the Key terms?
- Anything they said about the animation, speed or colours.
- Keep any help you gave in a separate column from their first answer.

## After

- Fill the evidence-led decisions table: change made, declined or deferred, with the reason (no change is a valid result).
- Link the finished records from [the design rationale](../design-rationale.md), update [story-review.md](../story-review.md), then close #8.
