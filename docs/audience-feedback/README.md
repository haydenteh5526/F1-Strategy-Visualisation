# F1 Strategy Visualisation

Group Data Visualisation Project    Audience Feedback Form

Use with the story prototype (`streamlit run app\story.py`) or the images in `figures/austria-2026/`. Show one chart at a time without explaining it first. Write down answers as given, and record no names or student IDs.

## About the viewer

- Teammate or F1 fan?
- How often do you watch F1? Every race, some races or rarely.
- Have you looked at lap-timing data before? Yes or no.

## For each chart

Charts: tyre stints, pace, tyre age, positions and VSC lap times.

1. What does this chart show?
2. What is the main point, in one sentence? Note roughly how long this takes; the target is about a minute.
3. Is any word, colour or label confusing?

## Checks from the audience brief

- What does a gap between two drivers mean here?
- Is pit-lane time the same as the time the car is stopped?
- Does tyre age tell you how worn the tyres are?
- What would you conclude about the race? Note any conclusion the data cannot support.
