# Austria 2026 tyre-stint timeline

`tyre_stints.png` is the presentation/export image; `tyre_stints.svg` is the scalable version. Both are generated by `scripts/plot_stints.py` from the committed prepared CSVs, with no download or telemetry required.

## Reading the chart

- Each driver has a separate row, grouped by team. Row order is not a performance ranking.
- A stint is a continuous run on one tyre set. Colours and S/M/H letters identify soft, medium and hard compounds.
- Segment lengths count recorded race laps inclusively: `LastLap - FirstLap + 1`. They do not show total tyre age; a set can already have recorded usage before its stint.
- Lap cells are centred on integer lap numbers. For example, laps 1–18 occupy coordinates 0.5–18.5.
- A diamond at 18.5 labelled L18 means entry on lap 18 and exit on lap 19. This is a schematic boundary marker, not an exact within-lap timestamp or a pit-duration measurement.
- Same-compound tyre changes remain separate segments, including HAD's medium-to-medium change and the hard-to-hard changes for VER, RUS, ANT and LEC.
- All selected laps are shown, including pit, interrupted and other pace-ineligible laps. The 361-lap pace subset would leave gaps and is not used for this timeline.

## Reproduce

From the repository root, with requirements installed in `.venv`:

```powershell
& ".\.venv\Scripts\python.exe" scripts\plot_stints.py
& ".\.venv\Scripts\python.exe" -m unittest discover -s tests -v
```

Paths default to the repository location, so the script also works when launched from another directory. Optional `--data-dir` and `--output-dir` arguments select alternate folders. Validation remains specific to this six-driver, 71-lap race.

## Design choices and limits

The chart retains individual drivers, labels compounds beyond colour, and preserves same-compound stops. Automated validation checks reproducibility and chart consistency, not audience understanding. Audience testing remains pending; no final pace or strategy-performance claim is made.
